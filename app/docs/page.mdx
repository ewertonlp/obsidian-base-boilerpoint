# Obsidian Base Documentation

Welcome to the official documentation. Here you will learn how to configure your project, connect to Supabase, and start accepting payments in minutes.

## 1. Environment Variables

To get started, you need to configure your `.env.local` file. Copy the example file and fill in your keys:

```bash
cp .env.example .env.local
```


## 2. Authentication Flow
We use Supabase for authentication. It's fast, secure, and gives you a Postgres database out of the box. Here is a quick example of how to retrieve the user on the server side:


import { createClient } from "@/app/lib/supabase/server";

export async function getUser() {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  
  return user;
}
